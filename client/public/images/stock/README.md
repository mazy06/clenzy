# Bibliothèque photo Baitly

Douze planches WebP de 16 cellules et une photo individuelle sans marque, pour 224 références. Chaque cellule est carrée ; le composant StockThumbnail utilise la position de la cellule, sans chargement d'image distante. Les variantes de taille partagent volontairement la même photo. Les noms restent la source d'identification du produit.

Les quatre premières planches sont documentées ci-dessous. Les huit nouvelles planches et leurs prompts figurent dans [EXPANSION.md](./EXPANSION.md). La cellule historique cleaning/1 (capsules gel) est remplacée dans le catalogue par les visuels précis de laundry-dishes : pastilles solides, capsules gel, capsules de lessive et tablettes de lessive.

Images créées avec le mode intégré Imagegen, puis encodées en WebP (qualité 82). Aucune photo de fournisseur ou marque tierce. Sources PNG conservées dans le dossier de génération Codex.
